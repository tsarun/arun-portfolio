# Arun TS — Portfolio (tsarun.com)

Personal portfolio of **Arun TS**, Senior AI Product Manager (16+ years across AI, Telecom, Fintech, and Banking; 12+ years in product delivery & ownership; 8+ years as PO/PM).

A fast, zero-dependency static site — no build step, no external frameworks, and no backend required. Open `index.html` locally or deploy directly via GitHub Pages.

## Key Features

- **Interactive Production RAG & Agentic Architecture Diagram:** Clickable 4-stage SVG pipeline detailing enterprise chunking/governance, RAG & agentic workflows, golden-dataset evaluation, and live CCAI/GCP telemetry.
- **Arun's AI Concierge:** Self-built floating recruiter chatbot with streaming responses, quick-select prompts, and natural keyword routing.
- **Interactive Bento Grid Impact Section:** Mouse-tracking radial spotlight cards and scroll-triggered animated metric counters.
- **60-Second Recruiter Mode:** One-click executive brief summarizing production metrics, squad/IC ownership scope, awards, and immediate availability.
- **Theme-Aware Design:** Light and dark mode toggle using modern `oklch()` color tokens and crossfading WebP hero portraits.
